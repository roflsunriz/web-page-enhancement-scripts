# 公開ページ実測の証拠

2026-10-02、分離Chrome 154.0.8037.93、390×844、Android相当UA、認証を持ち込まない一時コンテキストで取得。

- `*.json`: 要求URL、本体DocumentのHTTP応答、各段階の動画readyState/paused/currentTime、DOM属性、矩形、標準／汎用スワイプのイベントと全画面状態。
- `*-<試行番号>.png`: そのページで操作した後のスクリーンショット。番号は各JSONのattempts順に対応。
- `loaded` / `frame-loaded`: 注入前の状態。
- `native-*`: サイト標準操作のみ。スクリプト未注入。
- `generic-*`: 配布スクリプトを一時注入後。GM関数はこの一時ページ内のスタブ。

TwitchのVODは一覧の実リンクから発見した。bilibiliの2候補は表示中の視聴videoがなく操作未確認。ニコニコはpausedのまま全画面切替を測定しており、継続再生を確認した証拠とは扱わない。詳細は `docs/video-swipe-site-audit.md`。

生データの生成クラスは観測の保存用であり、コードの判定には使わない。公開ページのみでCookie・認証ヘッダー・ストレージ値は取得していない。これらは今回のローカル証拠であり、サイトUIが変わると再調査が必要。
