# YouTube古い順再生の公開ページfixture

2026-10-13、未ログインの分離Chromeで以下の公開ページを開き、公式の古い順フィルターが提供する `/youtubei/v1/browse` の応答を採取した。

- https://www.youtube.com/@LOCAL58TV/videos ：最初の応答13本、継続なし。
- https://www.youtube.com/@YouTube/videos ：最初の応答30本、次の応答28本と継続。全件数と終端は実サイト検証の記録を参照。

保存したJSONは抽出に必要な公式フィールドと公開動画ID・タイトル・継続トークンだけに縮約した。Cookie、認証情報、視聴者データ、画像、追跡パラメーターを含めない。トークンはスキーマを検証する資料であり、回帰では外部へ送らない。

単体テストは採取時点の件数と形式を検証する。ブラウザ回帰では同じrendererの3動画を使い、継続・重複・異常応答をオフラインで再構成する。すべてのリクエストを満たすため、外部通信は発生しない。

実ページの確認は `node scripts/youtube-oldest-player-live.mjs`。現在の公開ページのデータから取得・再生を行うためネットワークが必要。画面・実測結果は `artifacts/youtube-oldest/` に保存する。fixtureを更新するときは実応答の構造を確認して縮約し、件数や順序の変化を根拠とともにテストへ反映する。
