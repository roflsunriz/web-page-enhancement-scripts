# YouTubeのチャンネル動画を古い順に連続再生

[配布用スクリプト](https://raw.githubusercontent.com/roflsunriz/web-page-enhancement-scripts/refs/heads/main/dist/youtube-oldest-player.user.js)をTampermonkey等へ導入し、YouTubeのチャンネルの「動画」タブを開きます。右下の「古い順に連続再生」を押すと動画一覧を最後まで取得します。「最初から再生」で、最も古い動画から同じタブで順に再生します。

再生中のパネルには現在の番号、総数、タイトル、前へ・次へ・連続再生の一時停止／再開・終了を表示します。一時停止は次の動画への自動移動を止めます。動画自体の再生／一時停止にはYouTubeのプレーヤーを使います。ブラウザが自動再生を拒否した場合は、プレーヤーの再生ボタンを押してください。

再生順は同じタブ内で保持し、再読み込みしても続きから使えます。別の動画へ通常のリンクで移動した場合や「終了」を押した場合は連続再生を終了します。新しいタブやブラウザを閉じた後の永続的な再生履歴は提供しません。非公開・削除済み・地域制限等で再生できない動画は、必要に応じて「次へ」で進めます。

対象はPC用 `www.youtube.com` の「動画」タブです。チャンネルがこのタブで公開する一覧を対象とし、Shorts・ライブ配信の別タブは含みません。ログイン・APIキー・アカウントの再生リスト作成は不要です。一覧取得は上限10,000本で、通信失敗や構造変更時には途中の一覧で再生を始めずエラーを表示します。

取得中は「キャンセル」で中断できます。再生できない場合は動画タブを再読み込みして再試行してください。連続再生中は関連動画へ移動しないよう、YouTubeの自動再生を一時的にオフにし、「終了」や通常のページ離脱で元の値へ戻します。最後の動画や一時停止中も、終了するまではオフを維持します。利用停止は先にパネルの「終了」を押し、userscript managerで無効にして再読み込みします。ブラウザが異常終了した場合など、離脱処理が動かなかったときはYouTubeの自動再生を手動で戻してください。

日本語、英語、中国語、ヒンディー語、スペイン語、フランス語、アラビア語、ポルトガル語、ベンガル語、ロシア語、ウルドゥー語に対応します。更新はuserscript managerの更新確認を使います。ローカルでビルドした場合は `dist/youtube-oldest-player.user.js` の再読み込みも利用できます。

## 現在の仕様と保守

2026-10-13に未ログインの公開ページ2チャンネルで確認しました。公式の「新しい順・人気の動画・古い順」の3フィルターから、ページが提供する古い順の継続トークンを取得します。翻訳文言や動画の相対投稿日を使って並べ替えません。最初の並べ替え応答で3番目のフィルターの選択状態も確認し、追加読み込みがなくなるまで取得します。

これはYouTubeの非公開内部形式に依存します。フィルターの順序変更は選択状態だけでは検出できないため、更新時は実ページの表示順と応答を再確認してください。現行 `chipBarViewModel` / `lockupViewModel` と従来の `feedFilterChipBarRenderer` / `videoRenderer` を扱います。現行形式の採取データは `test-fixtures/youtube-oldest-player/` に縮約して保存しています。

公式の自動再生は関連動画へ進みます（[YouTubeヘルプ](https://support.google.com/youtube/answer/6327615?hl=ja)）。本スクリプトは、タブに保存した現在の動画ID・URLの動画ID・公式プレーヤーの現在IDが一致し、広告表示中でない場合だけ動画終了を処理します。終了処理で次の通常視聴URLを開き、最終動画や連続再生停止中は関連動画への遷移を止めます。YouTubeが不明なURLパラメーターを削除するため、独自のURLマーカーを再生順の維持条件にしません。

通常視聴ページでは、HTMLの `ended` より早くプレーヤーの `onStateChange` が終了状態0を通知する場合があります。両方を処理し、二重の移動を防ぎます。パネルはページ本文の準備後に設置し、状態通知の更新ではボタンを交換しません。
