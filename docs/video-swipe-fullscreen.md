# 動画の上下スワイプ全画面

`video-swipe-fullscreen` 1.0.1 は、Webページで操作できる HTML `video` 要素へ上下ドラッグを追加する別userscriptです。公開mainから導入できます。

1. [配布用userscript](https://raw.githubusercontent.com/roflsunriz/web-page-enhancement-scripts/refs/heads/main/dist/video-swipe-fullscreen.user.js)を使用中のuserscript managerへ導入します。手元の `dist/video-swipe-fullscreen.user.js` を新しいスクリプトへ貼り付けても導入できます。
2. ページを再読み込みし、動画中央付近から1本指またはマウス左ボタンで上へ64px以上、1.2秒以内にドラッグして離します。
3. このスクリプトで開いた全画面の中央付近から下へ同じようにドラッグすると、通常表示へ戻ります。

横画面ロックが許可されれば横向きになります。未対応・拒否時は全画面を維持し、手動回転の案内を表示します。全画面自体が未対応・拒否された場合は通常表示のままです。動画の標準全画面ボタンやEsc・戻る操作でも解除できます。

タップ、横シーク、斜め・短い・遅いドラッグ、複数指、ボタンやスライダーからの操作は対象外です。動画の左右10%・上下18%以上の端と小さい動画も対象外にして、標準操作を優先します。動画中央からの上方向ドラッグは本機能に割り当てるため、ページをスクロールするときは動画の外から操作してください。ページ全体の `touch-action` やスクロール設定は変更しません。

video要素そのものが全画面になる場合の案内は、対応ブラウザのPopover APIを使って表示します。このAPIに対応しないブラウザでは、その表示形態での案内が見えないことがあります。

## サイト側の操作を優先する

サイトが開始・移動・終了イベントをキャンセルした場合、イベントを途中で止めた場合、操作中に全画面状態が変わった場合、先にサイトが全画面のユーザー操作権を消費した場合は処理を見送ります。サイトが開いた全画面をこのスクリプトから下スワイプで解除することもありません。

サイトのすべてのイベントハンドラや、遅れて実行される独自ジェスチャーを完全検出することはできません。競合するサイトではuserscript managerのメニューで「このサイトで動画スワイプ全画面を無効にする」を選び、ページを再読み込みしてください。有効に戻すメニューも同じ場所にあります。設定はホスト名ごとにmanagerへ保存し、サイトの保存データへ書き込みません。埋め込み動画は埋め込み元ホストの設定が必要になることがあり、managerのフレーム別メニューを確認してください。

実ページで見つかったTwitchのシーク専用面は、プレイヤーの識別属性と操作面を組み合わせて対象外にしています。ホスト名だけで「標準スワイプ全画面あり」と判断しません。[主要サイトの操作確認](video-swipe-site-audit.md)を参照してください。

## ニコニコ版と併用する

`sp.nicovideo.jp` は旧ニコニコ専用版との重複を避けるため、汎用版では初期状態が無効です。専用版を利用中ならそのままにしてください。同梱の `nico-mobile-swipe-fullscreen` 1.0.1 には協調マーカーがあり、汎用版を有効にしても視聴ページでは専用版を優先します。

汎用版だけで利用したい場合は、専用版を無効にしたうえで同サイトの有効化メニューを選び、再読み込みしてください。旧専用版1.0.0には協調マーカーがないため、汎用版を手動で有効にする際は必ず専用版を無効にします。

## 対応範囲と制限

|対象|扱い|
|---|---|
|複数動画・動的追加・SPA|操作位置の動画をその都度探します。移動・動画削除で所有する全画面とロックを解除します。|
|プレイヤーoverlay|動画と同じ矩形で1本の動画だけを含む祖先にある操作面を対象にします。別枠のoverlayや複数動画を覆う曖昧な面は誤操作防止のため見送ります。|
|iframe|managerがそのフレームにもスクリプトを注入する必要があります。別オリジンの動画を親ページから直接操作しません。`allow="fullscreen"` 等の許可がなければ全画面にできません。sandbox・Permissions Policyも適用されます。|
|shadow DOM|公開されたopen rootを探索します。closed rootやブラウザ内部の動画UIは探索しません。|
|native controls|端を避けますが、ブラウザ内部の操作面を完全には識別できません。競合時はサイト別無効化を使います。|
|iPhone等のOS管理全画面|DOMに下スワイプが届かないため、ネイティブ全画面への自動切替は行わず標準ボタンを案内します。|
|キャンバス・独自描画・保護されたプレイヤー|HTML videoが操作可能なDOMにない場合は対象にできません。|

全サイト・実機での成功保証ではありません。Android/iPhone実機とmanager経由での注入・永続化はこのPCだけでは確認できていません。停止・復旧はmanagerで本スクリプトを無効にして再読み込みします。今回、認証情報・既存プロファイル・OS/ブラウザのセキュリティ設定は変更していません。

開発・検証手順は [how-to-update.md](../how-to-update.md)、確認結果は [verification.md](../verification.md) にあります。
